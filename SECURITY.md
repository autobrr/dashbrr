# Security Policy

## This Is a Fork

This repository is a personal fork of [autobrr/dashbrr](https://github.com/autobrr/dashbrr).

**Vulnerabilities in the core application** (not related to fork-specific changes) should be reported to the upstream project. Check their repository for a security contact or open a private advisory there.

**Vulnerabilities introduced in this fork** — GitHub Actions workflows, automation scripts, or any other fork-specific changes — can be reported here.

## Reporting a Vulnerability

Email: **anders.eriksson@denied.se**

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

You can expect an acknowledgement within a few days. If the issue is confirmed, a fix will be pushed to `develop` and the reporter credited (unless anonymity is preferred).

## Supported Versions

Only the latest commit on `develop` is actively maintained.

| Branch    | Supported |
|-----------|-----------|
| `develop` | ✅        |
| older     | ❌        |
