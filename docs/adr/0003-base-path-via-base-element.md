# The base path reaches the browser through one `<base href>`

The base path reaches the browser through one `<base href>` element. The server writes it into `index.html` once, at start. All frontend URLs are relative, and there is no window variable. qui and autobrr use a window variable and string rewrites. qui then had to fix each URL type (HTML, CSS, dynamic imports, manifest, service worker files) one at a time. With `<base>`, the browser resolves `fetch`, `EventSource`, service worker registration, `<link>`, and `<script>` addresses, so that bug class does not occur. The source `index.html` has a literal `<base href="/" />`, so the Vite dev server and a root deployment operate with no server help. Only three callers need the base path as a string: the router, the redirect to the login page on a `401`, and the Plex forward address. They read it from `document.baseURI`.
